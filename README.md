# GoFin

# 📊 Portfolio Manager Web App

A lightweight web application built with **Node.js + Express + HTML/CSS/JS** that helps users track and compare their stock portfolios in real-time using Yahoo Finance data. This project was developed as part of a portfolio management training program.

---

## 🌟 Features

- 📈 Real-time stock quotes via Yahoo Finance
- 🗂️ Custom watchlist (“Favorites”) with add/remove functionality
- 🧮 Compare two portfolios side-by-side with a dashboard
- 📊 Historical price charts using Chart.js
- 🔍 Search stocks by ticker
- 💡 Responsive UI design inspired by [Futunn Quote](https://www.futunn.com/quote)

---

## 🧱 Tech Stack

| Layer        | Technology                  |
